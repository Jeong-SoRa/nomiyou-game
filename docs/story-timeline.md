# 노미요 게임 스토리 타임라인 (2026-09-19 기준)

> 코드에 구현된 흐름을 날짜순으로 정리한 문서. 설계 결정의 배경과 열린 질문은
> `docs/superpowers/specs/2026-09-16-nomiyou-story-design.md` 에 있다.
> 하루는 **침대에서 자야** 넘어가고, 그날 해야 할 일이 남았으면 잠들 수 없다(할 일 목록은 화면에 보여주지 않음).

## 공통 규칙

- 방송: 데스크 `E` → 노미요 오프닝 멘트 → `E · 계속하기` → 고성 탈출 게임 화면. `Esc` 로 종료.
- 고성 게임 진행(위치·연 문·열쇠)은 세션 동안 저장되어 다음 날 이어서 한다. 탈출하면 초기화.
- 방 안 파닥이 대사: 1~2일 따뜻함 → 3~4일 불안 → 5일~ 무서운 목격담 → 6일~ 가끔 점프스케어 "보내줘".
- 숲의 시간대: **1~3일차는 밝은 아침**(하늘색 배경, 햇살, 초록 나무, 가로등·현관등 꺼짐) → 4일차 해질녘 → 5일차부터 밤(달빛, 안개, 가로등). 우상단 배지 MORNING / DUSK / NIGHT. 방 창문 밖 디오라마도 같은 시간대를 따른다.
- 으스스함: 4일차부터 방/숲이 붉고 어두워져 7일차에 최대. 배경음도 잔잔한 곡 → 으스스한 곡으로 섞임.
- 숲 깊은 곳(오두막 반대편 끝)에 **커다란 나무 상자**(노미요 키의 두 배)가 1일차부터 보인다. `E · 상자 살펴보기`를 하면 날짜별 혼잣말만 나오고 열리지 않는다. 7일차에 곡괭이로 부순다.
- 고성 게임 속 파닥이: 1일 안 보임 → 2~4일 얼핏얼핏(반투명, 지나갈 수 있음) → 5일~ 또렷, 말을 걸면 오염 대사 후 소멸.

## DAY 1 — 평범한 방송

1. 방에서 시작. 데스크에서 방송 시작.
2. 고성 게임 첫 접속 안내문: "당신은 누구 소유인지 모를 오래된 건물에서 눈을 떴습니다. 「나가는 길」을 잘 찾아보세요. 조심하세요. 너무 늦어지면 돌이킬 수 없어집니다."
3. 홀을 돌아다니며 조사. 왼쪽 아래 방의 구겨진 쪽지: **"나갈 수 없어. 놓아주지 않을거야. 아무도 못나가"**
4. 갈라진 벽에서 청동 열쇠 → 왼쪽 문을 열고 들어가면 노미요: "그럼 오늘 방송은 여기까지 할까. 여러분들 내일 또 봐요. 미요미요" → `E · 방송 끄기`.
5. 방으로 돌아오면 "...배고파. 밖에 나가서 뭐 좀 찾아 먹자." → 숲의 포도 덩굴에서 포도를 따 먹음.
6. 침대에서 잠 → DAY 2.

## DAY 2 — 괴물

1. 아침 혼잣말: "어제 성에서 본 그 쪽지... 신경 쓰지 말자. 오늘도 방송 해야지."
2. 방송 접속 → 어제 들어간 왼쪽 방에서 이어서 시작. **한 발짝 움직이는 순간** 점프스케어와 함께 고성의 괴물이 나타나 쫓아온다.
3. 성 곳곳의 오래된 옷장(`E`)에 숨으면 괴물이 멀어진다. 멀어지면 `E` 로 나옴. 잡히면 **게임 오버** → 방송이 끊기고 방으로 (진행은 마지막 저장 지점 유지).
4. 안쪽 방의 낡은 일기: "오늘도 %#$을 봤다. 재미있었다. #@독 버튼을 눌렀다." 가 잠깐 보였다가 치지직 → 문장 전체가 깨짐 → 노미요 "...이게 뭐야." → 일기를 버림.
5. 잠 → DAY 3.

## DAY 3 — 붉은 눈

1. 아침: "파닥이가 아까부터 안절부절못하네."
2. 방송.
3. 방 안 파닥이: "밖에서... 눈이 빨간 무서운 걸 봤어. 같이 가서 확인해 줄래?" → 파닥이가 동행.
4. 숲의 풀숲을 확인하면 나무 사이에서 붉은 눈 두 개가 잠깐 나타났다 사라짐. 파닥이: "...사라졌어. 봤지?"
5. 잠 → DAY 4.

## DAY 4 — 노크

1. 아침: "어제는... 좀 이상했어. 그래도 방송은 해야지." 방과 숲이 조금 붉고 어두워지기 시작.
2. 방송 중 18초쯤 **문 두드리는 소리**(쾅쾅쾅쾅) + 화면 흔들림. 채팅: "방금 무슨 소리 들린 거 같은데?" 노미요: "모르겠어요 하하".
3. 방송 후 현관 옆 발자국 자리를 확인 → 아무것도 없음. 멀리서 노크 두 번.
4. 잠 → DAY 5.

## DAY 5 — 힌트 수집

1. 아침: "파닥이가 힌트 얘기를 했었지. 탈출 지점이라니, 뭘까."
2. 방송(성 안 파닥이가 또렷해져 말을 걸 수 있고, 대화 후 글리치와 함께 사라진다).
3. 방 안 파닥이와 동행 → 숲에 흩어진 힌트 쪽지 3장: "숲 깊은 곳의 나무 상자. 아무도 그 안을 본 적이 없다." / "상자는 손으로는 열리지 않는다. 부술 것이 필요하다." / "혼자서는 안 된다. 함께 온 이가 있어야 한다."
4. 잠 → DAY 6.

## DAY 6 — 남은 힌트

1. 아침: "힌트가 두 개 더 남았댔지."
2. 방송. 파닥이와 힌트 2장: "오두막 뒤 장작더미. 아침이 일곱 번 오면 그곳에 곡괭이가 있다." / "상자 안의 것을 부수면 모두 돌아간다. 부수지 않으면 아무도 떠나지 못한다."
3. 잠 → DAY 7.

## DAY 7 — 상자를 부수다 (엔딩 분기)

1. 아침: "...오늘이야. 아침이 일곱 번 왔어. 곡괭이를 찾아서, 파닥이랑 그 상자를 열어보자." (방송 없음)
2. 방 안 파닥이에게 말을 걸어 동행: "...노미요. 오늘이야. 곡괭이를 찾아서, 그 상자까지 같이 가 줄래?"
3. 힌트를 다 모은 뒤(=7일차)에만 오두막 뒤 장작더미에 **곡괭이**가 나타난다 → `E · 곡괭이 집기` (동행 필요). 노미요: "...정말 있었어. 곡괭이. 가자. 숲 깊은 곳의 상자로."
4. 숲 깊은 곳의 커다란 상자 앞에서 `E · 상자 부수기 n/6` 을 **여섯 번** 누른다. 매번 곡괭이 소리와 함께 상자가 흔들리고 앞면의 갈라진 틈(밝은 속살)이 조금씩 길어진다(노미요: "...부순다!", "하압!", "...갈라진다.", "조금만 더!", "거의 다 됐어!"). 여섯 번째에 **파사삭** — 판자들이 사방으로 날아가 떨어지고 안에서 **커다란 '좋아요'(👍) 석상**(소맷단, 손바닥, 층층이 접힌 손가락 네 마디, 위로 뻗은 엄지)이 드러난다. 노미요: "...이게 뭐야. '좋아요' 버튼...? 석상이야."
5. 파닥이들(동행 + 숲의 파닥이 + 방에 있던 구독 파닥이들까지)이 석상 주위로 몰려와 **아우성**을 친다: "부숴줘!!", "빨리 부숴!", "노미요, 그거 부숴줘!!", "지금! 지금 부숴!!", "제발 부숴줘!!", "그게 우릴 붙잡고 있어!!" (약 5초, 돌아가며).
6. 아우성 한창일 때 **화면이 지직거리고**(줄무늬 글리치 + 치지직 소리) 시뻘건 **시스템 경고창**이 점프스케어처럼 튀어나온다(붉은 플래시 + 스탭 소리 + 흔들림): **"그걸 부수면 넌 혼자가 될거야. 부수지마."** 경고창은 잠시 화면을 압도한 뒤 위로 물러나고, 그 아래 선택지가 뜬다. 컷신 중에는 이동·상호작용이 잠긴다.
7. 선택 "석상을 어떻게 할까?" — 게임 UI 풍 좌우 큰 버튼(마우스 클릭 또는 `1`/`2`):
   - **1 부순다** → "...미안. 그래도 부술게." → 석상이 무너지고(잔해) 파닥이들이 "고마워." 하며 작아져 사라짐 → "...조용하네." → 밝은 엔딩 **〈부수다〉**: 노미요는 혼자 남지만, 며칠 뒤 현실로 돌아간 구독자들이 채팅으로 돌아온다.
   - **2 부수지 않는다** → "...못 해. 너희가 없으면 난..." → 비명 + 공포 모드 → 파닥이들이 그 자리에서 **숲의 괴물**(`src/characters/monster.js`: 노미요 1.5배, 대파 없음, 온몸 검정, 뾰족한 주둥이, 길쭉한 이빨, 새빨간 눈)로 커지며 변한다 → 붉은 엔딩 **〈남기다〉**: "보내줘. 보내줘. 보내줘." 노미요는 혼자가 되지 않았지만 아무도 놓아줄 수 없게 되었다.
8. `R` 로 처음부터.

디버그: `?day=7&world=forest&companion=1&done=recruit&pickaxe=1&smash=1` (상자 앞에서 바로 부수기), `?smash=hits|statue|warn|choice|rubble|monster` (그 단계 화면으로 바로), `?monster=1` (노미요 앞에 괴물 모델 배치).

## 아직 코드에 없는 것 (설계 문서의 열린 질문)

- 4일차 이후 방문을 두드리는 괴물이 창문으로 보이는 장면, 5~6일차 방송 중 "보내줘" 소리.
- 파닥이 개별 캐릭터(이름·과거 구독자 사연).
- 고성 미니게임 후반(더 많은 방, 오염 3단계의 정확한 트리거).
