# 노미요 게임 스토리 타임라인

> **기준 설계 문서는 `docs/game_timeline.md` 입니다 (2026-09-29부터).**
> 이 파일에 있던 7일차 구조(붉은 눈·노크·힌트 쪽지·7일차 곡괭이)는 폐기되었고, 코드는 `game_timeline.md` 의 6일차 구조를 따릅니다.
> 설계 결정의 배경은 `docs/superpowers/specs/` 에 있습니다.

## 구현 메모 (문서에 없어 정한 것)

- 열매 먹기(3개): 숲의 열매 덩굴에 송이 세 개가 달리고 하나씩 `E` 로 먹는다. 매일 다시 달린다.
- 4일차 '노미요 인형', 5일차 '나무상자 드러내기'는 다음 날 진행에 꼭 필요하므로 침대에서 잠들기 위한 조건에 포함했다 (안내문만 뜨고 할 일 목록은 보이지 않는다).
- 지하 2층 화장실 세면대는 처음엔 물이 나오지 않고(파닥이 유령 조우), 유령이 말을 한 뒤에는 다시 물이 나온다. 화로는 벽의 그림이 알려 주는 순서(남 1 · 북 2 · 서 3 · 동 4)로 끈다. 순서가 틀리면 전부 다시 붙는다.
- 레이어 설계: 고성 지도 중심 타일 (15,11) = 오두막, 1타일 = 6m. 지하 3층 남쪽 다이얼 문 (15,21) → 숲 (0, 50.5) = 파닥 동상(나무 상자) 자리. 숲은 ±58m, 우물은 서쪽 (-46, 20), 석탑은 북쪽 (±2.4, -44), 헛간 (0, -50).
- 숲(2026-09-29 저녁 요청): 나무 약 1,100그루(다섯 종류, 충돌 있음)와 구불구불한 오솔길(오두막→동상/우물/석탑 + 막다른 곁길), 카메라와 노미요 사이를 가리는 나무는 반투명, 숲에서는 왼쪽 위에 나침반(N = 석탑 방향). 포도송이는 나무 26그루의 잎 바깥쪽(잎이 넓게 퍼진 높이)에 하나씩 매달려 있고 `E` → "포도를 먹을까요?" → 예. 우물도 `E` → "우물을 사용할까요?" → 예. `?berry=1` 로 첫 송이 앞에서 시작.
- 시작 화면: 시작하기 / 이어하기. 진행은 날이 바뀔 때 `localStorage['nomiyo.save']` 에 {day, flags} 로 저장되고, 이어하기는 그 날의 시작 지점(침대 옆)에서 시작한다. 우상단 HOME/DAY 배지는 숨김. 설정창 아래에 단축키 안내.
- 엔딩 3: 검은 화면에 "내일도 오늘도 같은 하루" 제목 + 크레딧. 엔딩 4: GAME OVER 화면, 버튼(`R`/`Enter`)으로 그날 처음부터. 엔딩 1·2: 기존 〈부수다〉/〈남기다〉.
- 6일차 방송은 곡괭이를 얻은 뒤 "게임을 종료할까요?" 에서 YES 를 고르면 끝난다.

## 디버그 파라미터

`?day=N`, `?world=forest`, `?at=x,z`, `?cam=x,y,z`, `?done=stream,berries`, `?flags=noteFound,ghostMet,hasBarnKey,barnOpened,hasDoll,hasAmpoule,statueSeen,crateRevealed,canWater`,
`?stream=now&nointro=1` (바로 게임 화면), `?gfloor=N` (고성 시작 층), `?gat=x,y[,dir]`, `?gkeys=KeyE`, `?ginv=cup,cupWater,a,b,doll,ampoule`,
`?chase=1` (2일차 추격 바로 시작), `?dial=1`, `?confirm=1`, `?gameover=1`, `?pickaxe=1`, `?smash=1|hits|statue|warn|choice|rubble|monster`,
`?ending=bad|true`, `?epilogue=1[&board=1]`, `?credits=true|bad|same`, `?nofade=1`, `?silent=1`, `?steps=N`. 디버그 파라미터가 있으면 시작 화면을 건너뛴다.
