# 노미요 게임 스토리 디자인 (진행 중 초안)

> 상태: **DRAFT / 브레인스토밍 진행 중** — 아직 최종 승인 전. 이전 세션이 저장 없이 종료되어, 대화 소실을 막기 위해 중간 체크포인트로 커밋함.

## 지금까지 확정된 결정 사항

- **복구 범위**: 이전 세션 스토리 내용은 기억나지 않음 → 처음부터 새로 브레인스토밍.
- **톤**: 귀여움 → 공포 반전 (평소엔 힐링/일상 스트리머 컨셉, 특정 트리거로 분위기가 뒤집히며 진짜 정체/비밀이 드러나는 반전형 공포).
- **핵심 미스터리 축**: 파닥이들의 정체/운명.
- **파닥이 정체**: 과거 시청자/구독자가 갇힌 존재. 노미요의 방송을 좋아하다 돌아가지 못하고 파닥이로 변해버림.
- **노미요의 인지**: 전혀 모름, 본인도 피해자. 플레이어와 함께 진실을 파헤치는 구조.
- **가해자/원인**: 특정 인물이 아니라 숨은 **'구독' 계약** — 시스템/저주 그 자체. "구독하기"라는 행위 자체에 걸린 규칙이 사람들을 가둠.
- **방 vs 숲의 의미**: 방(집) = 시청자에게 보여지는 안전한 '방송부스'. 숲(밤의 숲) = 구독자들이 실제로 갇혀 있는 진짜 공간. 방↔숲 전환(문)이 "방송 온/오프"의 경계와 대응.
- **결말/공략 구조 (A안, 하이브리드 — 채택)**: 
  - 방과 숲 곳곳의 메모/단서를 모으며 '구독 계약'의 진실이 점진적으로 드러나는 메인 흐름.
  - 파닥이 개별 인터랙션으로 "과거 어떤 구독자였는지" 짧은 정체가 드러남 (선택적 심화 콘텐츠).
  - 얼마나 많은 파닥이를 알아보고 상호작용했는지에 따라 마지막 확정 장면의 결말 톤(배드/뉴트럴/굿)이 달라짐.
  - 기각된 대안: B) 메모 수집형 단일 결말(작업량 최소, 감정선 약함), C) 파닥이 해방 중심 다중 결말(감정 임팩트 최고지만 작업량 큼).

## 현재 제시 중인 세부 섹션 (사용자 승인 대기)

### 1. 세계관 설정 (제안됨, 미승인)

- **표면**: 노미요는 방에서 매일 라이브 방송을 하는 여우 스트리머. 시청자가 '구독'하면 파닥이(병아리)로 방송에 "합류"한다는 컨셉. CHAT 칠판은 실시간 채팅 표시 장치.
- **이면**: '구독'은 실제로는 시청자 일부를 이 세계로 끌어들이는 계약. 구독자는 서서히 현실감을 잃고 파닥이 모습으로 숲 어딘가에 갇힘.
  - 방의 파닥이들 = 아직 완전히 갇히지 않은 초기 단계.
  - 숲의 존재들 = 이미 오래 갇혀 자아를 거의 잃은 후기 단계 (대비 연출).
- **노미요 자신**: 과거 '구독'했던 시청자 중 하나였거나 시스템에 의해 발탁된 존재였으나, 지금은 완전히 잊고 진행자 역할을 맡고 있음. 그녀가 방송을 계속할수록 계약이 계속 새 희생자를 끌어들임 — "피해자가 가해 시스템의 톱니바퀴가 됨"이라는 아이러니가 핵심 긴장.

## 다음 단계 (재개 시 여기서부터)

1. 위 "세계관 설정" 섹션에 대한 사용자 승인/수정 받기.
2. 캐릭터 섹션 (노미요, 파닥이 대표 몇 명의 구체적 정체/사연) 제시.
3. 메모/단서 진행 구조 + 파닥이 해방 인터랙션 구체 설계.
4. 결말 분기(배드/뉴트럴/굿) 트리거 조건 설계.
5. 톤/연출 가이드 (공포 모드 전환 연출과 스토리 비트 연결).
6. 전 섹션 승인 후 최종 스펙 정리 → `superpowers:writing-plans`로 구현 계획 전환.
