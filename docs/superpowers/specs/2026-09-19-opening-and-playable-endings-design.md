# 오프닝 인사 + 실제로 진행되는 엔딩 (2026-09-19)

> 사용자가 지정한 연출을 그대로 옮긴 설계. 기존 텍스트 엔딩 화면(〈부수다〉/〈남기다〉 본문)은 없어지고, 두 엔딩 모두 "인게임(고성) 화면이 자동으로 진행되는 장면"을 거쳐 엔딩 크레딧으로 끝난다.

## 1. 물주기 소리 수정 (`src/systems/audio.js`)

- 기존 `sfx.water()` 는 0.2초 간격 노이즈 6방(각각 즉시 최대 볼륨에서 시작)이라 "탕탕탕"으로 들렸다.
- 새 구현: 노이즈 **한 줄기**(물주기 길이만큼)에 0.35초 페이드인·0.4초 페이드아웃 봉투, 밴드패스 주파수를 LFO 로 천천히 흔들어 "쏴아". 잎에 떨어지는 톡톡 소리는 12ms 램프업으로 클릭 제거.
- `water(dur)` 로 길이를 받는다. 방의 화분 물주기는 1.6초, 고성 게임의 물 채우기/화로 끄기는 기본값.

## 2. 오프닝 (`src/main.js`)

- 게임을 처음 시작(1일차, 방, 디버그 파라미터 없음)하면 약 1초 뒤 노미요와 가장 가까운 파닥이가 노미요를 바라보며 말풍선 두 줄로 인사한다:
  "안녕 노미요. 오늘도 좋은 하루야." → "재미있는 방송 기대할게."
- 파닥이 옹알이 효과음은 기존 `sayLines` 관례를 그대로 쓴다.

## 3. 공통: 엔딩 자동 진행 모드 (`src/game/castle.js`)

- `startDemo({ monster })`: 저장을 무시하고 1층을 새로 만들어 오프닝 없이 시작. 플레이어는 미리 정한 경로(`DEMO_ROUTE`: 방향 토큰 + 멈춤 초)를 따라 자동으로 홀을 돌아다닌다. `monster: true` 면 첫 걸음에 괴물이 나타나 쫓아온다. 키 입력은 무시.
- `monsterDistance()`: 괴물과의 맨해튼 거리(없으면 Infinity). `freeze()`: 그 순간 화면을 멈춘다(잡히기 직전 정지).
- `closeDemo(lines)`: 노미요의 마무리 대사를 자동 진행(줄당 2.4초)으로 띄우고 끝나면 `onEvent('demoend')`.
- 데모 중에는 `stop()` 이 진행을 저장하지 않는다.

## 4. 배드엔딩 〈남기다〉 — "부수지 않는다"

1. (기존) 비명 + 파닥이들이 괴물로 변함.
2. 검게 페이드아웃 → 화면 전환 → **인게임 화면**(LIVE, 채팅창, 시청자 채팅 평소처럼). 노미요가 지하 1층을 탐험하고 괴물이 쫓아온다.
3. 괴물이 2칸 이내로 붙는 순간(또는 16초 안전 타임아웃) 화면이 멈추고 **쾅쾅쾅!** 문 두드리는 소리(현실의 노미요 방문) + 흔들림. 상태줄 "노미요: ...?"
4. 채팅: "노미요 무슨 소리 나지 않았어?" "누구왔어?" "파닭시켰어?"
5. 다시 **탕탕탕!** (더 빠르게) + 화면 지직.
6. 채팅창에 **붉은 글씨** "보내줘 보내줘 보내줘 보내줘" 가 도배된다(0.14초마다, 이름도 붉게).
7. **쾅쾅쾅** 점프스케어: 전체 화면에 커다란 "쾅!" → "보내줘!" 글자(떨림, 붉은 플래시, 비명).
8. 검게 페이드아웃 → 엔딩 크레딧.

## 5. 진엔딩 〈부수다〉 — "부순다"

1. (기존) 석상이 무너짐. 파닥이들이 한 명씩 **"드디어..."** 라고 말하며 **흰빛**(커지며 사라지는 빛 스프라이트)과 함께 사라진다(0.55초 간격).
2. **흰색**으로 페이드아웃 → 화면 전환 → 인게임 화면. 괴물 없이 노미요가 1층을 잠시(약 7초) 돌아다닌다.
3. 노미요: "자~ 여러분들 오늘 게임 여기까지 할게요." "시청해주셔서 감사하구요. 미요미요~" (자동 진행) → 채팅 인사 → 방송 종료(검은 페이드).
4. **에필로그(방)**: 파닥이 없는 방. 노미요가 데스크 앞에 서서 "피곤하다. 그만 잘까." 플레이어가 조작한다. 방은 더 이상 붉지 않다.
5. **침대 위 채팅 보드**(기존 CHAT 칠판을 침대 머리맡 벽 위로 옮김)에 글자가 적혀 있다:
   "미요미요. 하이" / "노미요 안녕" / "노미요 오늘 방송도 재미있었어." / "미요 우리 다음에 또 봐."
   - 침대 발치 앞에 서면 `E · 채팅 보드 보기`: 카메라가 보드로 줌인하고 글자가 한 줄씩 분필로 적히듯 나타난다. 끝나면 카메라 복귀, 노미요 "...고마워, 얘들아."
   - 보드를 보기 전에 침대에서 `E · 잠자기` 를 누르면: "어? 저게 뭐지?" "무슨 글자가 있네. 원래 있었나?" + 안내문 "침대 위 채팅 보드를 확인해 보세요". 잠들지 않는다.
   - 보드를 본 뒤 잠자기: 흰색 페이드아웃 → 엔딩 크레딧.

## 6. 엔딩 크레딧 (`index.html`, `src/main.js`)

- `#ending` 을 크레딧 롤로 바꾼다: 배경(진엔딩 밝은 크림 / 배드엔딩 검붉음) 위로 글줄이 아래에서 위로 올라온다(약 26초, Web Animations API). 마지막에 "R · 처음부터" 가 가운데 멈춘다.
- 내용: 제목 "노미요와 파닥이들", 엔딩 이름, 출연(노미요·파닥이들·숲의 괴물·고성의 괴물), 제작, 사용 도구, 마지막 한 줄(진: "시청해 주셔서 감사합니다. 미요미요~" / 배드: "보내줘").
- 크레딧 중에는 배경음 없음(`silent`).

## 7. 상태/락

- `cutscene`: 엔딩 연출 중 이동·상호작용·키 입력 잠금(M/O 는 허용). `ending`: 크레딧 표시 중(R 만 허용).
- `epilogue`: 진엔딩 에필로그(방). 이때 `loadWorld('house')` 는 파닥이를 만들지 않고, 으스스함은 0.
- 디버그: `?ending=bad|true` (분기 직후 장면부터), `?epilogue=1` (에필로그 방부터), `?credits=true|bad`.
